# 🧠 Deep Learning Assignments
Welcome to my Deep Learning Assignments repository.

This repository contains my practical implementations, experiments, and learning outcomes from the Deep Learning laboratory. The goal of this repository is to build a strong understanding of Deep Learning concepts by implementing algorithms and models from the basics to more advanced techniques using Python, TensorFlow, and Keras.

#🎯 Learning Objectives

Throughout these laboratory assignments, I will learn how to:

Understand the fundamentals of Deep Learning.
Work with datasets and perform data preprocessing.
Build and train neural networks.
Understand forward propagation and backpropagation.
Experiment with learning rates, epochs, and optimization.
Perform image classification using Convolutional Neural Networks (CNNs).
Understand important CNN components such as convolution, activation functions, pooling, flattening, and dropout.
Use pre-trained models for transfer learning.
Apply transfer learning to real-world image classification problems.
Evaluate Deep Learning models using accuracy, loss, confusion matrices, and predictions.
Visualize model performance using graphs.
Save and reuse trained Deep Learning models.

#🧪 Assignment Details

Assignment 1 — TensorFlow/Keras and Data Preprocessing

Objective:

Install and configure TensorFlow/Keras in Google Colab and perform basic data preprocessing.

Topics covered:

  TensorFlow and Keras setup
  Dataset loading
  Data preprocessing
  Normalization
  Train-test split
  Data visualization

Assignment 2 — Multilayer Perceptron (MLP)

Objective:

Design and implement a Multilayer Perceptron for classification using the Iris or Wine dataset.

Topics covered:

  MLP architecture
  Input, hidden, and output layers
  Activation functions
  Model training
  Classification
  Accuracy evaluation
  Confusion matrix

Assignment 3 — Forward Propagation and Backpropagation

Objective:

Implement forward propagation and backpropagation using TensorFlow/Keras and analyze how different training parameters affect model performance.

Topics covered:

  Forward propagation
  Backpropagation
  Loss calculation
  Weight updates
  Learning rate
  Number of epochs
  Performance analysis

Assignment 6 — Convolutional Neural Network

Objective:

Design and implement a Convolutional Neural Network for image classification using a Tomato or Soybean disease dataset.

Topics covered:

  Image preprocessing
  Convolution layers
  Filters and feature maps
  ReLU activation
  Pooling
  Flattening
  Dropout
  Softmax classification
  CNN training
  Image classification
  Accuracy and loss evaluation
  Confusion matrix and predictions

Assignment 7 — Transfer Learning

Objective:

Implement transfer learning using pre-trained models and compare their performance for image classification.

Models:

AlexNet

Topics covered:

Pre-trained ImageNet models
