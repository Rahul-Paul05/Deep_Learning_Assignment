# 🧠 Deep Learning Assignments

Welcome to my **Deep Learning Assignments** repository.

This repository contains practical implementations and experiments covering the fundamentals of Deep Learning, neural networks, image classification, and transfer learning.

The assignments are implemented using **Python, TensorFlow, Keras, Google Colab, and Kaggle datasets**.

The main goal of this repository is to understand Deep Learning concepts by implementing them practically, analyzing model performance, and visualizing the results.

---

## 🎯 Learning Objectives

Through these assignments, I will learn how to:

- Configure and use TensorFlow/Keras in Google Colab
- Load and preprocess datasets
- Perform train-test splitting and normalization
- Visualize datasets and model results
- Design and implement Multilayer Perceptrons (MLPs)
- Understand forward propagation and backpropagation
- Analyze the effect of learning rate and number of epochs
- Design Convolutional Neural Networks (CNNs)
- Perform image classification
- Use pre-trained Deep Learning models
- Apply transfer learning
- Compare different Deep Learning architectures
- Evaluate models using accuracy, loss, confusion matrices, and predictions

## 🧪 Assignment Details

### Assignment 1 — TensorFlow/Keras Setup & Data Preprocessing

**Objective:**  
Install and configure TensorFlow/Keras in Google Colab and perform data preprocessing, normalization, train-test splitting, and visualization.

**Topics covered:**

- TensorFlow and Keras setup
- Dataset loading
- Data preprocessing
- Normalization
- Train-test split
- Data visualization

### Assignment 2 — Multilayer Perceptron (MLP)

**Objective:**  
Design and implement a Multilayer Perceptron for classification using the **Iris or Wine dataset**.

**Topics covered:**

- MLP architecture
- Input, hidden, and output layers
- Activation functions
- Model training
- Classification
- Accuracy evaluation
- Confusion matrix

---

### Assignment 3 — Forward Propagation and Backpropagation

**Objective:**  
Implement forward propagation and backpropagation using TensorFlow/Keras and analyze the effect of different learning rates and numbers of epochs.

**Topics covered:**

- Forward propagation
- Backpropagation
- Loss calculation
- Weight updates
- Learning rate
- Number of epochs
- Performance analysis
