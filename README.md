# 🧠 Deep Learning Assignments

Welcome to my **Deep Learning Assignments** repository.

This repository contains practical implementations and experiments covering the fundamentals of **Deep Learning, Neural Networks, Computer Vision, Image Classification, and Transfer Learning**.

The assignments are implemented using **Python, TensorFlow, Keras, Google Colab, and Kaggle datasets**.

The main objective of this repository is to understand Deep Learning concepts through practical implementation, model training, performance evaluation, visualization, and analysis.

---

## 🎯 Learning Objectives

Through these assignments, I will learn how to:

- Configure and use TensorFlow/Keras in Google Colab
- Load and preprocess datasets
- Perform train-test splitting
- Normalize and prepare data for model training
- Visualize datasets and model results
- Design and implement Multilayer Perceptrons (MLPs)
- Understand forward propagation and backpropagation
- Analyze the effect of learning rate and number of epochs
- Design and implement Convolutional Neural Networks (CNNs)
- Perform image classification
- Work with real-world image datasets
- Use pre-trained Deep Learning models
- Apply transfer learning
- Compare different Deep Learning architectures
- Evaluate models using appropriate performance metrics
- Analyze model predictions and errors

# 📈 Results & Evaluation

Each assignment uses appropriate evaluation methods based on the problem being solved.

### 📊 Evaluation Metrics

| Metric | Purpose |
|---|---|
| **Accuracy** | Measures the percentage of correct predictions |
| **Loss** | Measures the model's prediction error |
| **Validation Accuracy** | Measures performance on unseen validation data |
| **Confusion Matrix** | Shows class-wise prediction performance |
| **Training Time** | Helps compare computational efficiency |
| **Model Comparison** | Compares different architectures and approaches |

### 📉 Result Visualizations

Results may include:

- Training vs. validation accuracy curves
- Training vs. validation loss curves
- Confusion matrices
- Sample predictions
- Classification reports
- Model comparison tables
- Performance graphs

Detailed results and visualizations are maintained inside the corresponding assignment folders.
